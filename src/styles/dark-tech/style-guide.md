# Style Guide — dark-tech（深空墨绿科技风）

> 本文档是 `dark-tech` 风格包给 **AI 编排分镜与编写定制互动镜头** 的唯一视觉决策规则。

## 1. Art Direction（整体艺术指导）

- **我们是谁**：冷静、精密、工程感、带宇宙深空呼吸感的技术讲解视觉语言。
- **适用题材**：AI 技术拆解、架构原理、开发工具教程、评测对比、命令行与 Agent 工作流。
- **Visual Spectrum（视觉张力）**：极简 80% / 理性 90% / 深空空间感 70% / 克制微光 30%。

## 2. 色彩角色分工（禁止乱用色）

| 角色 | 色值 | 唯一用途 |
| --- | --- | --- |
| 深空底色 | `#090B10` + 极微弱墨绿/深紫光晕 | 全局背景（保持 55%+ 留白） |
| 墨绿玻璃面 | `rgba(16, 30, 27, 0.58)` + `1px` 细描边 | 卡片、节点、窗口底面 |
| 翡翠绿主高亮 | `#34D399` | 当前激活态、关键词标亮、箭头、勾选完成 |
| 暖金副强调 | `#FDE68A` | 核心大标题点睛、关键数字、鼠标指针、单行字幕 |
| 警示红 | `#F87171` | 仅用于反面对比（`✕`、错误/痛点卡片），严禁大面积铺满 |

## 3. Composition Grammar（构图语法）

1. **一屏一主焦点**：屏幕中央只演 1 个核心概念（一个终端、一张工作台、一组对比或一个 8 宫格），绝不同时塞「左侧长文 + 右侧复杂图 + 底部多条注释」。
2. **留白底线**：有效内容占画布面积不超过 `45%～55%`，顶部保留 `46px` 章节导航条，底部保留 `110px` 给单行暖白无框字幕。
3. **关键词高亮纪律**：每句标题最多只用 `**关键词**` 高亮 1 处（2～6 字），严禁整行全亮翡翠绿。
4. **演过程不摆结果**：优先用打字机敲入、光标点选、元素飞落、光点连线展示因果过程。

## 4. 网页截图装裱规则

- 真实网页/数据表截图放入 `MediaScene` 时，必须包在暗色细描边圆角容器内（`borderRadius: 18`），配合柔和暗投影。
- 若需强调局部数据，使用 `#34D399` 翡翠绿或 `#F87171` 警示红细框精准标出，禁止叠加花哨箭头贴纸。

## 5. Anti-Patterns（反例边界：绝对禁止）

- ✕ 赛博朋克高饱和霓虹紫/荧光粉、大面积发光外框
- ✕ 一屏塞超过 4 条纯文字要点（像传统 PPT 翻页）
- ✕ 廉价 3D 渐变按钮、粗描边大字艺术字、卡通弹窗贴纸
- ✕ 无内容理由的持续剧烈抖动或高频闪烁
