# Style Guide — warm-editorial（暖纸红黑编辑风）

> 本文档是 `warm-editorial` 风格包给 **AI 编排分镜与编写定制互动镜头** 的唯一视觉决策规则。

## 1. Art Direction（整体艺术指导）

- **我们是谁**：温润、知性、克制、有纸质杂志与高质量专栏质感的方法论/观点讲解视觉语言。
- **适用题材**：趋势解读、认知方法论、产品体验复盘、个人成长、十条建议/避坑清单。
- **Visual Spectrum（视觉张力）**：人文编辑感 85% / 留白呼吸感 85% / 克制装饰 20% / 明暗节奏感 75%。

## 2. 色彩角色分工

| 角色 | 色值 | 唯一用途 |
| --- | --- | --- |
| 暖纸渐变底 | `#FDF5D7` → `#F7E5A8` | 全局主底色，模拟柔和纸张质感 |
| 炭黑衬线字 | `#1F2933`（宋体/衬线体） | 大标题与核心观点，稳重有权威感 |
| 朱砂红高亮 | `#C83E2B` | 标题内 1 处核心动词/反差词标红（如「**退步了**」「**长期合作**」） |
| 深墨绿强调 | `#1B4D3E` / `#18221F` | 正面结论卡片、矩阵中的 `featured` 深色锚点卡 |
| 暗底反转屏 | `invert: true`（切 `dark-tech`） | 遇到「故障、底层原理、严厉警示」时穿插 1～2 屏刷新视觉 |

## 3. Composition Grammar（构图语法）

1. **标题靠衬线 + 局部标红抓眼球**：标题字号大、行距舒展，每句只标红 1 处核心词（2～4 字）。
2. **善用「总—分—总」与明暗反转**：清单类长视频建议开场用多卡片总览，中段穿插 1～2 屏 `invert: true` 暗底反转，结尾用 2×3 或 2×5 矩阵卡片收尾。
3. **底部字幕**：使用浅炭黑半透明胶囊底（`rgba(31,41,51,0.55)`）+ 暖白字，确保在浅黄底上清晰可读且不突兀。

## 4. 网页截图装裱规则

- 真实截图直接放于暖纸底上，配柔和暖灰投影与细棕边框（`rgba(120,86,40,0.18)`），局部重点用朱砂红 `#C83E2B` 方框精准框选。

## 5. Anti-Patterns（反例边界：绝对禁止）

- ✕ 荧光色、高饱和纯红纯蓝、科技感强霓虹光斑
- ✕ 满屏无衬线粗黑体堆砌（会丢失杂志编辑感）
- ✕ 连续超过 3 屏都是相同纯文字列表（必须穿插对比、插画隐喻、真实截图或暗底反转）
- ✕ 写实摄影照片直接硬贴无留白
